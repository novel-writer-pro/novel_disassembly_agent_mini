## 章节级笔记

### ch2 二姑卫荭 ✅
- **结构骨架完整**:求功法→受阻→提供两选项(签契/银两)→主角内心权衡→章尾钩子
- **优点**:章尾"想起厨下案板底下压着的那截萝卜——腌进坛子就变了味,可若不腌,过两天就烂了"——比喻贴合卫图身份(灶房视角)
- **问题**:杏的台词"咋了,跟霜打似的"+"那你还愁啥"——口语自然,但接下来的"卫图压低声音""杏瞪眼""杏担忧道"全是叙述者复述,没让人物自己说话

### ch3 养生功法 ✅✅(本批最佳)
- **优点**:
  - "图字简单,不过三十六个呼吸坐姿"——具象细节
  - "练了二十余遍,眼前金紫命格浮现一行字迹"——金手指出现得克制,不喧宾夺主
  - 章尾"十年方成" + "大器晚成" + "二十七岁"——三层呼应,反爽文节奏
- **问题**:赵伯出场"慢悠悠""沉吟半晌"——人物动作描写偏向套语

### ch4 珍惜眼下 ✅
- **优点**:
  - 内心戏密度高——卫图算赎身银两的逻辑链清晰,体现"务实"性格
  - 章末"养生功是假的"钩子是 4 章里最有力的悬念
- **问题**:
  - 章末显式标记 `（章末钩子：卫图走到阮家门前...）` ——这是又一类**prompt-bleed**,与雪中 ch4 的 4 行结构标签同根
  - "（本章完）"标识也不该出现在 prose 里

### ch5 婚后筹谋 ✅
- **优点**:婚后日常—商议—决断—修炼,4 段式结构干净
- **问题**:
  - "（本章完）"再次出现——确认是 prompt 教 LLM 加上的
  - 标题"婚后筹谋"被 LLM 改写,原章是"婚事敲定"——LLM 自作主张
  - 大奶奶的"利落人去府城采买药材"——但前一章 ch4 已经是"大奶奶决定赎身银 2.5 两",时间线乱

## 跨章观察

1. **整体保真度比诛仙稳定**:卫图 IP 是原创基线小说,LLM 对其"风格"的拟合反而更松(没有"必须像 X 作家"的约束),所以 prose 自然度反而更高
2. **章末显式标签问题**:weitu ch4 出现"（章末钩子：...）"+"（本章完）"两类污染,xuezhong ch4 出现 4 行 method 标签——**prompt-bleed 是跨本系统问题**,不是单本特性
3. **method_notes/comparison_notes 末尾的 12-15 行 `1:rhythm, 2:ending_hook, 3:dialogue` 残留**——commit f60827d 修了根因,但本批旧产出仍带

## 决策建议

- **ch3 养生功法是 P1 级 reference candidate**,可拿去做 pairwise winner
- weitu IP 适合作为 Phase-4 的"低基线对照组"——观察 style/rhythm/dialogue 信号在原创小说上的工作情况(没有名家文风可比)
- 三本横评结论:**雪中(6.2)≈ 卫图(6.2)> 诛仙(5.8)**,与"prose 上限取决于原作语调能否被模型 abstract"相关
