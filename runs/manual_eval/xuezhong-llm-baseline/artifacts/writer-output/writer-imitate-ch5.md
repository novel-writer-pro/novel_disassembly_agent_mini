## Draft Text
长白山来了位绝代风华的美人，成了这两日黑水城仅次于镇北王世子游历归来的重大消息。前去猎奇的人差点踏破了客栈门槛，生意火爆，每当那位果然绝色的美人出房进餐就食，更是挤满了一睹风光的登徒子。一开始只是年轻纨绔参与其中，后来上了年数在床铺上心有余而力不足的富贾也来欣赏美色，一致大叹秀色可餐。好事者都说这位姑娘比黑水城头号花魁还要动人几分，一些个走出过黑水城见过世面的老爷也都说这辈子没见过如此娇艳的女子。那位来自外地的美人不动声色，将所有人视若无物，喝只喝黑水城最好的烈酒，进食则细嚼慢咽，但不如小家碧玉那般扭捏含蓄，别有风情，只是桌上搁着的两柄长短不一的剑，让不少心怀不轨的登徒子知难而退。哪有良家闺女单独出门并且佩剑的，而且还是两把？越是娇艳出奇的花朵，越不容易采摘，这是身为膏粱子弟必须有的觉悟。既然世子殿下回城了，那么美人现世，世子殿下的风姿身影还远吗？答案跟预料得有些出入，世子殿下这次踩点比众人想象中要晚了三天，但终归是来了。他一出现，所有人都自觉地离开客栈，废话，跟世子殿下抢姑娘抢花魁，哪个家伙没有付出血的代价？世子殿下早就说过了：大家一起出来混纨绔这一行，没老百姓想的那么容易，也讲究鼠洞蛇路和规矩门路，得对得起肩膀上那颗脑袋。所以黑水城纨绔走出去邻近州郡，尤其自豪，瞧不起当地的富家官宦子弟。客栈一下子空荡荡，外头门可罗雀，但掌柜的还是堆着谄媚笑脸，双手奉上珍藏多年的最好烈酒。亲爹啊，以往喝酒从不给半文钱的世子殿下转性了，一下子打赏了张五千银票。掌柜一溜烟躲在柜台后面，双手颤抖捧着银票，他绝不担心世子殿下只是在美人面前装豪爽，因为出了世子口袋的银子还真没听说过要回去一分一毫。大体来说，黑水城惊惧世子殿下半点不假，可无法无天闹腾了这么多年，没谁要死要活闹上吊跳河的。例如那些个有幸被“请”进镇北王府的小娘子，事后都说只是与世子殿下一下赏景一番，留下了肚兜之类的贴身物，并没有被迫做那云雨之事。世子殿下坐在白狐儿脸对面，亲自启封了烈酒，酒香瞬间弥漫，自作多情端了一碗过去，没接。世子殿下放下后哑然笑道：“放心，我是做过下蒙汗药的勾当，但知道你是内力深厚的高手，就不自取其辱了。再说了，我又没断袖之癖龙阳好，你怕个屁？难不成担心我夺你的两柄剑，那也太小瞧我了吧？”白狐儿脸微微一笑，终于拿起酒碗，轻轻喝了一口，仅仅是这几个再普通不过的细微动作，差点就让阅美无数的世子殿下晃了眼，恨不得捶胸顿足问苍天为啥这样的美人是男子啊。白狐儿脸的声音软糯悦耳，道：“能把魔门宝典《吞金宝箓》随手送人的，的确不像是会垂涎这两柄剑的人。”世子殿下补充道：“不是‘不像’，是‘不是’。”从偶然相逢到勉强相识的一路五个月时间里，白狐儿脸其实一直惜言如金，不像今天这么愿意搭话。记得那时张嘴第一句话便是晴天霹雳，“我是男儿身”，起先世子殿下不信，但相处久了，花丛老手的世子殿下不得不信了这个。因为白狐儿脸话虽不多，但习惯言出必行，例如杀那劫径的匪人，说全杀了绝不剩下一个半死的。说得了秘籍要护送世子殿下进黑水城，即便他完全可以反悔，一走了之，但仍然跟到了黑水城。再就是白狐儿脸给人的感觉，的确不是一个娘们，喝酒跟喝水一般，杀人如拾草芥。世子殿下心碎了。说好了的，要给弟弟娶天下第一美女做媳妇，如果是个娘们，多简单的事，到了他的地方，就是天下十大高手，也得乖乖留下。现在只希望在弟弟下山之前去会一会那江湖上传得有板有眼的消息，只求那四个号称天下四大美女的姐姐们不要愧对名号。给弟弟一个，自己留两个，剩下一个就让偌大一个江湖去争抢好了。白狐儿脸一手端碗，一手摩挲着一柄剑。剑是九长九短十八般兵器中公认的九长之首，被尊为兵中之皇。这柄剑长三尺二寸，柄长两寸半，精美绝伦，相较造型朴拙的另一柄要更美观好看，很符合世子殿下的审美。世子殿下估摸着重量大概在两斤左右，但白狐儿脸某次心情好的时候透露此剑重十斤九两。世子殿下没啥大优点，出身镇北王府，小时候天天在武库爬上爬下，就是见过世面，一下子就信了，至于那柄从未出鞘的窄剑，白狐儿脸也从未言语提及，对世子殿下来说是个不大不小的遗憾。世子殿下举杯道：“我敬你。”白狐儿脸不易察觉地撇头，望向窗外夜色，缓缓道：“我要去东海。”

## Method Notes
- 严格遵循原章‘美人现世引发轰动→纨绔围观→世子登场清场→掌柜献酒打赏→世子与白狐儿脸对饮交谈→揭露白狐儿脸身份与特质→世子内心动机（为弟弟求亲）→章尾白狐儿脸提出行动意向’的叙事节奏与信息释放顺序。
- 保留‘美人引发骚动-权势清场-秘密对话-动机揭示’的核心冲突推进链条，将场景从陵州龙门客栈置换为黑水城对应场所，将‘刀’置换为‘剑’以适应新世界设定，但保持其作为危险与身份象征的功能。
- 将‘世子殿下’的身份背景与‘白狐儿脸’的武功高强、言出必行特质作为人物选择逻辑的核心，其互动模式（试探、防备、某种程度上的认可）与原章一致。
- 章尾钩子‘我要去东海’既承接了白狐儿脸的个人目标（原章为‘进陵州’），也为主角（世子殿下）提供了下一步可执行的行动方向（跟随或协助），并为家庭线（为弟弟求亲）与身份线（世子需要在江湖中活动）的交叉埋下伏笔。
- 严格遵守硬约束：战力未升级，未引入未准备的大设定（如东海的具体情况）。遵守软约束：家庭线（为弟弟娶妻）与身份线（世子的江湖活动）在章尾通过白狐儿脸的‘去东海’意向发生交叉，世子需要做出是否同行或如何利用此机会的决策。
- 优先补足与原章对应的中段阻力与行动转向，不要只保留开头与结尾。
- 继续约束角色反应，避免把克制型推进写成情绪化爆发。
- 如涉及关系变化，补足中间证据，不要只写结果。
