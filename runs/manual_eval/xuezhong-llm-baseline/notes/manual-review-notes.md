## 章节级笔记

### ch2 白狐儿脸 ✅
- **优点**:
  - 折冲都尉李沉舟视角开场——比直接写徐凤年回府更有镜头感
  - 入城轰动那段(青楼老鸨梳妆打扮)还原了原作"恶名远扬"的轻佻调性
  - 父子打闹"鞋!穿上鞋!天凉!"——这一句神还原徐骁
- **问题**:
  - 白狐儿脸出场时"白袍胜雪"——原作描述是青衫,这里换了
  - "桃花眼中闪过一丝冷意"——是套语,不是烽火的写法

### ch3 两个酒窝 ⚠️ scaffold-only 失败
- LLM 没产出 prose,只有 method_notes 与 comparison_notes
- 但 risk_gate_notes 里有非本章内容("鬼厉""九尾天狐"),与诛仙 ch2 是同样问题
- **共性 hypothesis**:LLM context 串了——可能 batch 跑的时候 prompt 没正确隔离

### ch4 去那座山摘山楂 → 听潮亭论事 ⚠️ 严重问题
- LLM **更改了原章 title**("去那座山摘山楂" → "听潮亭论事")
- LLM **改写而非仿写**——原章是徐凤年带姜泥/老黄、调侃日常,这一章硬塞进了一个"龙虎山老道士"+"听潮亭取山楂"的全新情节
- **致命问题**:章末出现 4 行结构标记泄露到 prose:
  ```
  目标明确：进入听潮亭，寻找老道士口中的"山楂"...
  阻力浮现：听潮亭守阁奴皆是深不可测的老怪物...
  主角回应：徐凤年决定不再如以往般嬉闹进出...
  章尾钩子：徐凤年走向听潮亭...
  ```
- 这是**新一类污染**——prose 里直接出现 method 框架的中文标签
- 需要单独追根:这些 4 行标签来自哪个 prompt template

### ch5 天下第一美人 ✅✅(本批最佳)
- 整章读完几乎不需要修改,prose 质量接近商用
- **优点**:
  - "世子殿下心碎了"+"给弟弟一个,自己留两个,剩下一个就让偌大一个江湖去争抢好了"——典型烽火"凉薄+幽默"
  - 白狐儿脸"声音软糯悦耳"vs 男身的反差包袱抖得自然
  - 双剑(长短不同重量)的细节加得合理(原作背景知识对得上)
- **问题**:
  - 个别历史事实搬错了:"魔门宝典《吞金宝箓》"——这不是雪中悍刀行体系里的东西
  - "陵州龙门客栈"被改成"黑水城"——不一致(ch2 还是陵州)

## 跨章观察

1. **章节连续性断裂**:ch2 是陵州,ch5 是黑水城——这是 batch 跑时 LLM 重新生成的世界观,没记住前一章设定
2. **ch4 的 4 行结构标签**是新一类污染——P0-1 修了 action queue 尾巴,但 LLM **自发把 method 章节内化进了正文**。这需要 prompt 层面修(教 LLM "method 思考写在 method_notes,prose 不要带标签")
3. **风格基线最高**——同样的 LLM,雪中悍刀行的 prose 比诛仙更有原作气质;说明烽火戏诸侯的"凉薄叙事"反而比萧鼎的"庄重排比"对模型更友好

## 决策建议

- **本批 ch5 是 P1 级 reference**,可以直接拿去 pairwise 评估
- ch4 的"4 行结构标签泄漏"是**新发现的 prompt 层 bug**,优先级仅次于 P0-1
- ch3 和诛仙 ch2 同 fail 模式 → 可能是上游 LLM provider 的 batch 隔离问题,值得查 helicone trace
