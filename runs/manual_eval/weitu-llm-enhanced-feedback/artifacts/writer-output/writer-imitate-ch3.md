卫图在黄宅偏门外等了近一个时辰，才被丫鬟领进二姑卫荭的厢房。卫荭正靠在软榻上嗑瓜子，见他进来，眉头微蹙：“你来作甚？”卫图躬身道：“侄儿想求二姑向阮武师说句话，容我跟他学几手养生功，强健体魄，也好将来为李宅多出些力。”卫荭冷笑一声：“学功？你年岁已大，练不出名堂。不如我替你向老爷讨个看库房的差事，安稳度日。”卫图摇头：“侄儿只想学功。”卫荭沉默片刻，放下瓜子：“我可以帮你这一次，但你须应我一件事——日后我若需你出力，你不得推辞。”卫图心中一紧，知道这承诺不轻，但为了改变现状，还是点头应下。卫荭便吩咐丫鬟去请阮武师。不多时，阮武师进院，打量卫图一番，从袖中丢出一本泛黄册子：“龟息养气功，拿去看。七日后还我。”说完转身就走，连多余的话都没有。卫图收好册子，拜别二姑。回到李宅马厩，他挑亮油灯，翻看册子，随后按图站桩演练。三十余遍后，眼前浮现字迹：“龟息养气功（1/100）：一日九练，五年即成。”他叹了口气，五年太漫长，但想到若能练成此功，或许能凭此在李家立功，换取脱籍之机，便又振作精神，继续将动作一遍遍练熟。
