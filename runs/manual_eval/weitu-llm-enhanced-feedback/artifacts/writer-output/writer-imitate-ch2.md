## Draft Title
二姑卫荭

## Draft Text
灶房的余烬还散着热气，卫图把今早劈好的柴码放整齐，心里却盘算着另一件事。前几日听李宅老仆说起，黄家老爷年轻时游历府城，曾得一本残卷，上面记着些养气吐纳的法子，能让身子骨强健、少生病。卫图一直想学些强身的门道——他如今是奴籍，赎身遥遥无期，但若能养好身子，往后做事也更有底气。思来想去，只有求二姑卫荭牵线。他取出积攒的工钱，到胭脂铺挑了盒金燕脂。比起紫云脂，金燕脂价格高出一截，送礼才不显得寒酸。到了黄宅侧门，门子通传后，青荷引他到前院厢房。等了约一盏茶，二姑卫荭推门进来，身后跟着两个丫鬟。她落座后，端起茶盏不紧不慢地饮了一口，才问：“卫图，怎么突然来了？家里可有急事？”卫图躬身行礼，将礼盒放在桌上推过去：“二姑安好，侄儿并无急事，只是有一事相求。”卫荭瞥了礼盒一眼，脸色稍缓，但语气仍淡：“说吧，何事？”卫图吸了口气，压低声音说：“侄儿听闻，黄老爷手里有一本养生功残卷，能强身健体。侄儿想求二姑帮忙，让侄儿抄录一份，或是习得其中几个式子。侄儿只想把身子练好些，日后赎身了也能多挣些银钱。”卫荭眉头一皱，把茶盏重重搁在桌上：“这事你从哪听来的？黄家的事，岂是你能打听的？那残卷是老爷的心爱之物，从不外传，连我都没见过几回。你一个做仆役的，学这些做什么，传出去让人笑话。”卫图低下头，声音却未退缩：“二姑，侄儿知道这要求唐突。侄儿不敢贪多，只求二姑帮忙问一句，若老爷愿意，侄儿定记二姑的恩情。若是不愿，侄儿也绝不再提。”他顿了顿，又从怀里掏出一个小布袋，里面是他攒的几十文钱，放在礼盒旁：“这些是侄儿的积蓄，权当给二姑买些茶点。”卫荭盯着他看了片刻，叹了口气：“你这孩子，倒是倔。也罢，我替你去问问老爷，但他答不答应，我可不担保。而且，若真得了，你须得答应我一件事——往后你赎身或发达了，得帮衬你堂弟一把。卫家虽穷，可血脉不能断。”卫图心中一凛，知道二姑这是要个承诺。他点了点头：“二姑放心，侄儿若有一日翻身，定不忘卫家人。”卫荭这才松口：“三天后你再来，到时候成与不成，都有个准信。”卫图千恩万谢，退出厢房。他走在街上，胸口微微发热。不管成不成，至少有了个念想。他攥紧拳头，暗下决心：往后每日早起，先练一个时辰的力气活，把底子打好，就算没有功法，也能撑起自己的一条命。
