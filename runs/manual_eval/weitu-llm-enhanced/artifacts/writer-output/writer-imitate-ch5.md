婚后筹划（求收藏，求追读）

## Draft Text
婚后第七日，天刚蒙蒙亮，杏已起身在灶房忙活。卫图活动完桩功，收拳吐气，感觉体内那股温热的气流比昨日又浑厚了一分。他捻了捻旱烟杆，没点，怕熏着新糊的窗纸。

杏端着两碗杂粮粥进来，搁在木案上，低声道：“卫哥儿，昨儿我听春兰姐说，大奶奶有意让外院的几个家仆去北坡新开的荒地上搭棚看青，年底多分两石粮食。”她顿了顿，看向卫图，“咱俩的月钱加起来，一年存不了几两。要是能揽下看青的差事，三五年就能凑够赎身的银子。”

卫图舀粥的手一停。赎身——这两个字像石子投进井里，在他心里荡开涟漪。他低头喝了口粥，道：“看青得罪人，荒地上常有野物和闲汉。大奶奶肯让咱们去？”

“春兰姐说，大奶奶念你成家后踏实，又有把式傍身，是信得过的。”杏咬了咬嘴唇，“只是……”

“只是什么？”

“只是得签三年死契，看青期间不得另接租地。若出了岔子，还要倒赔。”

卫图没接话，慢慢把粥喝完。他知道这是李宅给的机会，也是锁链。三年死契意味着不能同时租地种粮，攒钱的路径窄了；可若不接，凭现在这点月钱，赎身遥遥无期。他放下碗，拿起烟杆，这次点了火。

“杏，你怕不怕吃苦？”

“嫁你那天就不怕了。”杏低头缝补着褂子，针脚密实。

卫图吐出一口烟，目光沉沉：“那就去应。三年看青，我白日护地，夜里练功。等攒够了赎身钱，咱们就不是奴籍了。”他把烟杆在鞋底磕了磕，“孩子也能堂堂正正去私塾。”

杏眼圈微红，没再说话，只把缝好的褂子叠整齐放在床头。

当天午后，卫图去找了春兰，递了话。春兰去回李童氏，半晌出来，递给他一张盖了红印的契约。卫图按了手印，把契约折好揣进怀里。走出院子时，他抬头看了眼李宅高耸的院墙，心里默念：养生功再练三个月，内息便能转小周天，到时候力气涨上一截，看青的活儿就稳了。

夜里，杏在昏暗的油灯下数着铜板，盘算着三年能存多少。卫图靠在床头，闭目调息，感受丹田那股温热如细流般缓缓游走。屋外传来更夫敲梆子的声音，两声——刚过一更。

“卫哥儿，你说……赎身后，咱们是留在县里，还是回乡下？”杏轻声问。

卫图睁开眼，目光在烛火里晃了晃：“先赎身，再说不迟。李宅附近有间破院要卖，三十两银子。三年看青，加上你绣帕子攒的，差不了多少。”

杏“嗯”了一声，吹了灯。黑暗里，卫图又闭眼练了一遍导引，直到体内那股气流平稳下来，才沉沉睡去。

翌日一早，卫图扛着锄头出了门。北坡的荒地离李宅三里地，杂草齐腰，几棵歪脖树孤零零立着。他寻了块平整的坡地，开始搭草棚。日头毒辣，汗珠砸进土里，他却觉得脚下的地比昨天结实了些——养生功带来的改变，虽慢，却真切。

晌午，杏送饭来，篮子里除了杂粮饼，还有一小罐咸菜和两个鸡蛋。她看着卫图晒得黝黑的脸，心疼道：“要不……先缓两年再说赎身的事？”

卫图撕下一块饼，就着咸菜嚼了：“缓不得。趁年轻力气足，把这事办了，往后才松快。你安心在家，别总往这跑，晒黑了不好看。”他咧嘴笑了笑。

杏嗔了他一眼，转身要走，又回头：“夜里凉，草棚要扎厚些。”

“晓得了。”

目送杏的背影消失在田埂尽头，卫图钻进草棚，从怀里摸出一本手抄的《龟息养气功》残页，那是他花三个铜板从书铺淘来的。上面有几处注释潦草，但大致路线清晰。他盘腿坐下，按图导引，渐渐入定。

风从北坡刮过，带着黄土和干草的气息。远处青木县的城墙在热浪里扭曲，模糊成一道墨线。卫图觉得，那堵墙正一点一点靠近他。
