## Draft Text
卫图在黄宅前厅等候时，二姑卫荭终于从内院出来。她脸上的客套笑容掩不住眼底的疏远，卫图心里清楚，这次求人，人情要用在刀刃上。“侄儿想请二姑说句话，让阮武师教我一门养生功，不强求杀伐，只图个身板结实。”卫图躬身，语气放低。卫荭眉头一皱，指尖轻轻敲了敲桌沿：“养生功虽不珍贵，但也不是随便就能教的。你既已卖身李宅，我帮你这个口，往后可不能再有别的念想。”她话里的界限明了，卫图点头应下。卫荭这才唤来丫鬟，打发她去传话。半个时辰后，阮武师在侧院见卫图，随手丢来一本泛黄的《龟息养气功》图册：“七日后还我。”说完便转身指点两个锦衣少年练拳，连正眼都没给。卫图抱拳道谢，转身时听见身后一个少年说：“这种穷亲戚也来学武，不嫌丢人？”另一个嗤笑：“娘说了，以后少往来。”卫图脚步一顿，随即稳步离开。回到李宅马厩，他添完草料，摸出油灯，躲在侧屋里翻看图册。七个桩功、三十二张图，他照图站桩，姿势僵硬，呼吸错乱，但一遍遍硬磨。第三十五遍时，眼前浮现一行字迹：「龟息养气功（1/100）：一日九练，五年即成。」五年——他心头一沉，但翻开序言看到“养气功成，气从脉起，可入感气之境”，又缓了口气。五年能成，总比无望强。他收好图册，暗想，明日再去打听附近可有便宜药材，能助养气。
