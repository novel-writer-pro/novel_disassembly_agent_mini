小说拆书工具开发任务说明书

项目概述

开发一个基于LangChain/LangGraph/SkillKit的小说拆书工具，能够自动分析小说文本，提取结构化信息，构建知识图谱，并生成分析报告。工具需严格遵循我们之前讨论的分析流程和数据模型。

技术栈要求

  • •
    Python环境: /usr/local/miniconda3/bin/python
  • •
    Python版本: 3.10+
  • •
    核心框架:
    • •
      LangChain (最新稳定版)
    • •
      LangGraph (最新稳定版)
    • •
      SkillKit (LangChain技能包)
  • •
    数据库: PostgreSQL 14+ (唯一外部存储)
  • •
    向量存储: 使用pgvector扩展(PostgreSQL内嵌)
  • •
    大模型接入: Claude API (anthropic) 或 OpenAI API兼容接口
  • •
    缓存: Redis可选，但非必需
  • •
    异步支持: 必须支持asyncio

核心功能实现细节

1. 预处理模块

  • •
    章节分割算法: 实现启发式分割，支持多种章节标记模式
  • •
    元数据提取: 自动识别章节标题、编号、可能的卷/弧标记
  • •
    文本清洗: 去除无关字符，标准化格式
  • •
    输出: 结构化章节列表，每章包含位置元数据

2. 单章分析引擎

  • •
    上下文组装: 实现我们讨论的混合检索(embedding+bm25+graph)
  • •
    Prompt管理: 使用LangChain的PromptTemplate，支持变量注入
  • •
    分析维度: 必须实现我们讨论的所有14+个分析维度
  • •
    错误处理: 分析失败时重试机制，支持跳过问题章节
  • •
    结果验证: JSON Schema验证输出格式

  • •

6. LangGraph工作流设计

workflows/analysis_workflow.py

class NovelAnalysisWorkflow:
"""
主工作流，控制从预处理到报告生成的完整流程
必须支持状态持久化和断点续传
"""
复制
def init(self):
    self.graph = StateGraph(AnalysisState)
    
    # 定义节点
    self.graph.add_node("preprocess", preprocess_chapters)
    self.graph.add_node("analyze_chapter", analyze_single_chapter)
    self.graph.add_node("cross_analysis", perform_cross_analysis)
    self.graph.add_node("build_graph", build_knowledge_graph)
    self.graph.add_node("generate_report", generate_reports)
    
    # 定义边和条件跳转
    self.graph.add_conditional_edges(
        "analyze_chapter",
        should_trigger_cross_analysis,  # 条件函数
        {
            "continue": "analyze_chapter",
            "trigger_cross": "cross_analysis",
            "complete": "generate_report"
        }
    )
