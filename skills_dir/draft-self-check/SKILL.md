# Draft Self Check

Use this skill immediately after a draft is produced and before the formal gate/risk chain.

## Inputs
- Draft text
- Source imitation plan
- Constraint pack

## Outputs
- Blocking issues
- Likely gate failures
- Recommended revision actions

## Rules
- Prefer conservative failure prediction.
- Flag structure mismatch before style weakness.
- Do not rewrite the draft; only diagnose.
