# Writer Learning Lens

Use this skill after factual extraction and chapter analysis are both available.

## Inputs
- Validated chapter JSON
- Optional previous writer-learning notes

## Outputs
- Hook strategy notes
- Conflict progression notes
- Reveal-order observations
- Scene efficiency observations
- Transferable writing lessons

## Rules
- Focus on craft, not just plot retelling.
- Tie each lesson to observed chapter evidence.
- Prefer actionable lessons a writer can imitate or avoid.
