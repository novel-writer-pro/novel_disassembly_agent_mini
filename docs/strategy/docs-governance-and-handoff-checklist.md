# Docs Governance / Handoff Checklist

## 1. 每次跨能力线推进必须补
- [ ] 对应 feature checkout
- [ ] 当前真实样例 / fresh evidence
- [ ] 当前测试 / 评估状态
- [ ] 下一步闭环项
- [ ] release/handoff 文档同步

## 2. 文档组织原则
- canonical 入口优先
- 历史证据不删，但必须有索引归类
- 产品/架构/商务叙事与技术事实保持一致
- 不允许只在对话里沉淀关键结论

## 3. 发布前最小文档 smoke path
- [ ] `init-db`
- [ ] `db-capabilities`
- [ ] `export-branch-report`
- [ ] `show-whole-book-imitation-readiness`
- [ ] whole-book provider/sample evidence 可定位

## 4. 商务/白皮书侧必须能回答
- 我们到底是什么系统
- 与头部 AI 小说产品相比好在哪
- 哪些能力已经成熟
- 哪些能力可以快速逼近
- 商业价值主要落在哪些环节

## 5. 交接时必须显式说明
- 当前做了什么
- 当前还缺什么
- 当前风险是什么
- 当前测试/评估是否达标
- 下一步优先级和理由
