# 写手最佳实践：拆书→仿写→续写 完整操作指南

本指南面向使用 `novel-analyzer` 进行小说拆书与仿写的写手。基于真实示例小说《大器晚成》（卫图/李宅/命格/武举主线）的前 10 章数据，提供从零到一的最佳实践路径。

> **前置条件**：已完成小说的导入和拆书（`ingest` + `start-run` + `analyze-range`）

---

## 1. 能力总览

当前系统为写手提供了以下核心能力矩阵：

| 阶段 | 能力 | CLI 命令 |
|------|------|---------|
| 拆解 | 导入小说 + 自动切章 | `auto-run` / `ingest` + `start-run` |
| 分析 | 逐章六级流水线分析 | `analyze-range` / `analyze-next` |
| 知识 | 提取作者知识包 | `show-author-knowledge` |
| 检索 | 人物/事件/冲突检索 | `search-facts` / `ask-branch` |
| **仿写** | **拆书→仿写→风险控制→续写笔记** | **`writer-imitate`** |
| 风格 | 写作风格指纹 | `writer-style-fingerprint` |
| 对比 | 跨小说对比分析 | `writer-compare-novels` |
| 导出 | 多格式导出 | `export-*` 系列 |

## 2. 推荐工作流：从拆书到仿写

### 流程总览

```
第 0 步：导入拆书
  novel-analyzer auto-run ./novel.txt --title "示例小说"
  → 获得 run_id + branch_id

第 1 步：了解你的小说
  novel-analyzer show-author-knowledge <branch_id>
  → 人物/关系/规则/伏笔/动机树/成长弧

第 2 步：查看风格指纹
  novel-analyzer writer-style-fingerprint <branch_id>
  → 文风密度、叙事距离、对话占比

第 3 步：单章仿写实验
  novel-analyzer writer-imitate <branch_id> 3 "延续主角获得功法后的克制成长"
  → 仿写草稿 + 风险评估 + 续写笔记

第 4 步：从成功的仿写中提取续写笔记，指导下一章
  → 续写笔记自动传递（多章仿写时）

第 5 步：多章连续仿写
  novel-analyzer writer-imitate-range <branch_id> \
    "3:延续资源铺垫" "4:延续成长线" "5:引入新冲突"
```

## 3. 基于真实示例的仿写演示

以示例小说《大器晚成》为蓝本，展示完整仿写流程。

### 3.1 示例小说前 10 章脉络

根据系统拆书结果，前 10 章的推进逻辑如下：

| 章 | 标题 | 主要事件 | 人物状态变化 |
|----|------|---------|------------|
| 1 | 大器晚成 | 夜起喂马、发现命格「大器晚成」、准备找二姑 | 从日常劳作进入异常感知 |
| 2 | 二姑卫荭 | 告假、买胭脂、求见二姑、打听到黄宅武师 | 从劳动转向主动搜集修行线索 |
| 3 | 养生功法 | 请得养生功图册、开始学习《龟息养气功》 | 从「打算求法」到「已得功法、已开始练功」 |
| 4 | 珍惜眼下 | 认清阶级现实、苦练功法初见成效、婚事可能获准 | 修炼路线开始兑现 |
| 5 | 婚事敲定 | 与杏成婚、规划回乡报喜与攒钱 | 暧昧关系落实为婚姻 |
| 6 | 郑国官兵 | 婚后日常、郑国官兵骑队出现 | 引入外部世界动向 |
| 7 | 不入祠堂 | 回乡探亲、白阳县灾荒、家奴不能入祠堂 | 阶级困境被明确揭示 |
| 8 | 私房钱 | 脱籍考武举、杏拿出三两七钱、距离十两有缺口 | 从被动受限到主动争取身份 |
| 9 | 逼上绝境 | 租地种田、计算收成、李耀祖催交束脩 | 资源压力加剧 |
| 10 | 抬起头来 | 正式摊牌赎身、提出参加武举 | 从被动仆役到主动争取身份 |

### 3.2 写作特点（系统分析）

- **叙事距离**：mid — 靠近人物内心但不完全沉浸
- **文风密度**：balanced — 中等长度的段落，叙事与对话交替
- **冲突风格**：克制推进 — 主角不情绪化爆发，靠实干改变处境
- **钩子模式**：信息型钩子多于危机型钩子
- **人物逻辑**：卫图每一次行动都有明确的资源/关系/身份约束

### 3.3 仿写实验：第 3 章《养生功法》

以第 3 章为例，展示完整仿写流程。

#### 3.3.1 了解源章

```bash
novel-analyzer show-author-knowledge <branch_id> --focus-label "卫图"
```

关键信息：
- 源章标题：养生功法
- 核心骨架：求见二姑 → 说明来意 → 被拒绝学武 → 转为养生功 → 得到《龟息养气功》图册 → 开始练习
- 硬约束：阮武师的武功是独门武功，二姑只能提供养生功通道
- 关系敏感点：二姑对卫图起初有防备，但最终未拒绝
- 章尾钩子：七日后是否按约归还图册 + 命格进度提示

#### 3.3.2 执行仿写

```bash
# 基础版（skeleton draft，不消耗 LLM 额度）
novel-analyzer writer-imitate <branch_id> 3 "延续主角获得功法后的克制成长"

# LLM 版（生成完整正文草稿）
novel-analyzer writer-imitate <branch_id> 3 "延续主角获得功法后的克制成长" --use-llm --max-rounds 2
```

#### 3.3.3 阅读仿写报告

输出包含以下核心区块：

```
【仿写草稿】
  标题: 第3章 养生功法
  正文预览: ...

【阻塞问题】
  ✗ draft_too_short_for_gate             ← 草稿偏短，需补足中段

【建议修复】
  → 补足中段阻力、行动转向与章尾钩子之间的承接。

【续写笔记 — 下一章注意事项】
  章尾钩子: 卫图决定七日后归还图册，这期间需要抓紧练习...
  活跃人物: 卫图, 二姑, 阮武师, 翠柳
  关系状态: 二姑的态度仍保持距离
  未解线程: 命格的潜力尚未完全揭示
  世界规则: 养生功修炼需要时间积累，不可速成
  硬约束: 不要无铺垫升级战力
  禁止动作: 不要直接抄原文句式
  风险关注: 补足中段阻力与章尾钩子
  写作建议: 下次仿写时优先补足中段阻力
```

#### 3.3.4 理解续写笔记

`ContinuationNotes` 是仿写后自动产生的结构化续写指引，告诉写手下一章应该注意什么：

| 字段 | 本章值 | 对第 4 章的指导 |
|------|-------|----------------|
| `ending_hook` | 七日后归还图册 + 命格进度 | 第 4 章开头应承接修炼进度 |
| `relationship_state` | 二姑的态度仍保持距离 | 不要在下一章突然让二姑全力支持 |
| `unresolved_threads` | 命格的潜力尚未完全揭示 | 可以继续铺垫，不要急着完全揭示 |
| `world_rules` | 养生功需要时间积累 | 不要在第 4 章就写卫图练成 |
| `hard_constraints` | 不要无铺垫升级战力 | 保持克制成长节奏 |
| `forbidden_moves` | 不要直接抄原文句式 | 用你自己的表达方式 |

#### 3.3.5 第 4 章续写指导

基于第 3 章的续写笔记，第 4 章应该：

1. **承接修炼进度**：第 3 章结尾是「开始练习」，第 4 章可以写「连续数月高强度练习 → 体内生出暖流」
2. **保持克制成长**：源章写了「认清阶级难以跨越」，仿写时不能写成卫图突然变强
3. **关系推进**：杏的感情线继续推进（婚事可能获准），但不能跳过中间证据
4. **章尾钩子**：以李童氏「李家应该待你不薄」形成新悬念

## 4. 多章连续仿写（自动传递续写笔记）

当需要对连续多章进行仿写时，使用 `writer-imitate-range` 命令。

```bash
novel-analyzer writer-imitate-range <branch_id> \
  "3:延续资源铺垫" \
  "4:延续主角获得功法后的行动线并保持克制成长节奏" \
  "5:延续婚事推进与主角现实压力"
```

系统会自动将第 3 章的续写笔记传递给第 4 章作为策略输入，第 4 章的传给第 5 章。

输出：

```
═══════════════════════════════════════════════════════════
  多章仿写报告 — 3 章
═══════════════════════════════════════════════════════════
  第3章 | 评分:75 | 风险:low | 判定:needs_revision | 下一章续写钩子: 卫图开始站桩练习...
  第4章 | 评分:82 | 风险:low | 判定:aligned_but_needs_revision | 下一章续写钩子: 李童氏开始重新审视...
  第5章 | 评分:78 | 风险:low | 判定:needs_revision | 下一章续写钩子: 郑国骑兵出现在镇上...
```

## 5. 风险控制策略

### 5.1 仿写中的常见风险

系统在仿写过程中会自动检测以下风险类别：

| 风险域 | 检测内容 | 写手应关注 |
|--------|---------|----------|
| `character_ooc` | 人物行为是否偏离前文设定 | 卫图是否突然变得情绪化？ |
| `plot_logic_consistency` | 剧情推进是否有逻辑支撑 | 升级是否无铺垫？ |
| `world_rule_consistency` | 世界规则是否被违反 | 命格设定被改写？ |
| `relationship_consistency` | 关系推进是否有中间证据 | 二姑突然全力支持？ |
| `rhythm` | 节奏是否合理 | 钩子强度是否太弱？ |

### 5.2 针对本示例的风险关注点

基于系统对前 10 章的分析，这本小说的仿写应特别注意：

1. **克制成长节奏**：卫图是「大器晚成」命格，仿写时不能让他突然变强
2. **阶级约束**：家奴/身契是硬约束，所有行动必须在身份限制内
3. **关系证据**：关系变化要有中间事件支撑（如「掐了杏的屁股 → 婚事敲定」中间经过了李童氏的认可）
4. **信息型钩子**：这本小说的钩子偏信息型（如「官兵出现」「刀匪来源」），仿写时不要强行改成危机型

## 6. 风格指纹的应用

### 6.1 生成风格指纹

```bash
novel-analyzer writer-style-fingerprint <branch_id>
```

输出：

```
═══════════════════════════════════════════════════════════
  写作风格指纹 — branch=62e636f0-c901-4167-aa1c-aff3da9c83ef
═══════════════════════════════════════════════════════════
  分析章节数: 10
  文风密度: balanced
  叙事距离: mid
  对话占比: 0.xx
  平均段落长: xxx

  推荐风格轴:
    - 文风密度: balanced
    - 叙事距离: mid
    - 对话占比: ...
    - 平均章节长度: ... 字符

  仿写陷阱:
    ✗ 文风偏稀疏，仿写时易出现 prose_density_thin 风险。
    ✗ 叙事距离偏远，仿写时需注意读者代入感。
```

### 6.2 使用风格指纹指导仿写

- **文风密度 balanced →** 仿写时保持中等段落长度，不要写成长段落或碎片化
- **叙事距离 mid →** 可以让读者知道卫图的想法，但不要过度内心独白
- **克制推进 →** 不要写成情绪爆发型主角

## 7. 跨小说对比

如果你想把你的小说和另一部已拆书的小说做对比：

```bash
novel-analyzer writer-compare-novels <your_branch_id> <reference_branch_id>
```

输出：

```
═══════════════════════════════════════════════════════════
  跨小说对比分析
═══════════════════════════════════════════════════════════
  你的作品章节数: 10
  参考作品章节数: 25
  你的平均章长: 2400 字符
  参考平均章长: 3100 字符

  关键差异:
    - 你的章节平均长度明显短于参考
    - 你的对话占比明显低于参考作品

  仿写机会:
    → 从参考作品中学习钩子设计模式
    → 参考作品的冲突-应对-收束节奏

  写作建议:
    → 对比差异点，检查是否符合你的写作意图。
    → 重点关注冲突密度和节奏起伏的差异，而非表面字数。
```

## 8. 常见问题与解决方案

### Q: 系统提示 "draft_too_short_for_gate"

**原因**：草稿长度不足源章的 18%，系统判定信息密度不够。

**解决**：在目标描述中加入更具体的场景要求，例如：
```
# 太模糊
"延续主角的成长"

# 更好
"延续主角获得功法后的克制成长，包含一个中段阻力场景和明确的章尾钩子"
```

### Q: 系统提示 "structure_alignment_failed"

**原因**：仿写草稿的结构（场景推进顺序）与原章差异过大。

**解决**：查看原章的 `scene_beats`，在目标描述中参照这些节点。

### Q: 仿写草稿太像原文

**原因**：风格校准未充分表达差异化要求。

**解决**：在多章仿写时使用风格指纹作为指导：
```bash
# 先看风格指纹
novel-analyzer writer-style-fingerprint <branch_id>

# 再仿写，心中有数
novel-analyzer writer-imitate <branch_id> 3 "延续主角获得功法后的克制成长，保持叙事距离mid，文风密度balanced"
```

### Q: 续写笔记中的「禁止动作」太笼统

**原因**：约束包中的 `forbidden_transformations` 依赖于系统对源章的理解深度。

**解决**：在运行 `analyze-range` 之前，确保已完成了足够的章节拆书（建议至少 3 章），这样 planner context 中有足够的约束信息。

## 9. 进阶技巧

### 9.1 使用 LLM 生成正文

默认情况下 `writer-imitate` 生成的是 skeleton draft（结构草案）。要获得完整正文，使用 `--use-llm`：

```bash
novel-analyzer writer-imitate <branch_id> 3 "延续主角获得功法后的克制成长" --use-llm --max-rounds 3
```

`--max-rounds` 控制迭代次数。每一轮迭代会：
1. 重新生成或修订草稿
2. 重跑全部质量检查
3. 如果质量达标（评分 ≥ 80、风险 low、无阻塞），停止迭代

### 9.2 导出 JSON 报告

使用 `--output` 参数导出完整的结构化报告：

```bash
novel-analyzer writer-imitate <branch_id> 3 "目标" --output ./chapter3-imitation.json
```

JSON 报告包含完整的 `harness_report`（所有 harness round 的原始数据），可用于：
- 导入到其他写作工具
- 建立批处理仿写流水线
- 对仿写质量做量化追踪

### 9.3 从 QA 入手理解源章

在仿写之前，先用 QA 系统深入理解源章：

```bash
# 提问特定人物/事件
novel-analyzer ask-branch <branch_id> "卫图在第3章和第4章之间发生了什么变化？"

# 导出整条主线的 QA 上下文
novel-analyzer export-branch-qa-context <run_id> <branch_id> ./branch-qa.json
```

## 10. 术语速查

| 术语 | 含义 |
|------|------|
| `branch_id` | 分支标识，一个 run 下的主线 |
| `skeleton draft` | 结构草案：场景节拍 + 约束列表，不是正文 |
| `LLM draft` | LLM 生成的完整正文草稿 |
| `preflight` | 正式质量门控前的确定性预检 |
| `gate` | 质量门控：检查草稿是否通过最低质量标准 |
| `risk review` | 风险审查：OOC/逻辑/规则/关系一致性检查 |
| `ContinuationNotes` | 续写笔记：结构化地告诉写手下章该注意什么 |
| `harness` | 仿写控制层：编排所有 skills 和检查 |
| `strategy_input` | 策略输入：跨章节传递的修复优先级 |
