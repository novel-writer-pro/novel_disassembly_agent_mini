## 评分说明
- 2 = 好
- 1 = 一般
- 0 = 差

### 1. 连通性
- 非 stream 是否正常返回
- SDK `invoke()` 是否可用
- 是否出现 `choices: null` / `service waking up` / 429 等阻塞

### 2. JSON 稳定性
- 是否频繁 parse error
- 是否常见尾随解释、截断、缺逗号
- 是否经常需要 retry 才能成功

### 3. Summary
- 是否贴文本
- 是否过长
- 是否更像拆书摘要而不是剧情复述

### 4. Continuity
- 是否指出真实衔接
- 是否指出推进方向
- 是否抓到伏笔 / 冲突 / 规则变化

### 5. Window 总结
- 是否只是拼接
- 是否能看出阶段完成了什么

### 6. Writer-learning
- 是否为空
- 是否有具体“怎么推进 / 怎么解决 / 怎么留悬念”

### 7. 速度
- 单章耗时
- 5 章窗口耗时
- 是否适合长跑
