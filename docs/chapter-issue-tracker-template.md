# Chapter Issue Tracker Template

用于汇总当前整本稿子的章节问题，方便后续按优先级改写。

---

## 使用方法

每章至少标这几项：
- 当前评价
- 最大问题
- 是否影响弃书
- 优先级
- 下一轮建议动作

---

## 模板

| 章节 | 当前评价 | 最大问题 | 是否影响续读 | 优先级 | 建议动作 |
|---|---|---|---|---|---|
| 1 |  |  |  | P1/P2/P3 |  |
| 2 |  |  |  | P1/P2/P3 |  |
| 3 |  |  |  | P1/P2/P3 |  |

---

## 建议问题分类

- 钩子弱
- 节奏慢
- 爽点不足
- 情绪不够
- 人设飘
- 逻辑弱
- 信息太散
- 信息不足
- 世界观不稳
- 商业感不够

---

## 建议优先级规则

### P1
- 明显影响弃书
- 明显影响主角吸引力
- 明显影响主线推进

### P2
- 不至于弃书，但明显削弱阅读体验
- 可读但不够强

### P3
- 细节优化项
- 可延后处理
