# AI 小说系统产品战略 / Product Strategy

## 1. 产品定义
这不是通用 AI 写作器，而是面向小说创作与编辑流程的“内容理解 + 风险门控 + 受控生成”系统。

## 2. 核心用户
1. 长篇网文作者 / 工作室
2. 编辑 / 审校 / IP 开发团队
3. 小说平台工具链团队
4. AI 内容产品集成商

## 3. 产品价值
### 对作者
- 降低长篇连续性失控风险
- 提高回看、问答、检索效率
- 提供仿写辅助而不是纯代写

### 对编辑/平台
- 把“质量风险”提前结构化发现
- 减少人工只靠记忆读稿的成本
- 让审稿与复核有证据链

### 对系统方/商业方
- 可以做成平台能力，而不是单次模型调用
- 有更强的复用性、可治理性、可运营性

## 4. 商业化抓手
1. 拆书与知识库服务
2. 风险审查 / 读者踩雷预警服务
3. 仿写与续写辅助服务
4. 平台级编辑中台 / 运营中台能力输出

## 5. 产品路线
- Phase 1：拆书 + retrieval + branch report + QA
- Phase 2：risk semantic + review workflow + risk gate
- Phase 3：chapter imitation + harness + whole-book diagnostics
- Phase 4：governance + release gates + platformized operations
