# Docs Index / 文档导航

如果你第一次接触这个项目，建议按下面顺序阅读：

## 新手入口
1. `docs/final-handoff.md`
2. `docs/cli-operations-manual.md`
3. `docs/interface-manifest.md`

- `docs/agent-skills-and-embedding.md`：内部 staged agent / skills / ONNX embedding 说明
