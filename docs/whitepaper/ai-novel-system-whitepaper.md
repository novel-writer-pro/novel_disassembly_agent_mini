# AI 小说系统白皮书（草案）

## 1. 摘要
当前多数 AI 写作产品更像“生成器”，而不是“系统”。我们的方向是构建一个围绕小说生产全链路的 AI 中台：从拆书、抽取、检索、风险门控，到受控仿写、整书编排、评估治理与运营交接，形成可维护、可审计、可持续优化的系统能力。

## 2. 问题定义
长篇小说生产最大的难点不只是“写不出来”，而是：
- 信息量太大，回看成本高
- 连续性 / 规则 / 关系容易漂移
- 编辑和作者之间缺少统一证据面
- 生成内容缺乏受控修复与长期治理

## 3. 解决方案
我们提供的不是单次 AI 输出，而是：
1. 内容理解层
2. 风险审查层
3. 受控仿写层
4. 治理评估层
5. 文档交接与运营层

## 4. 差异化
- 可解释 risk gate，而非黑盒评分
- retrieval/graph/state/facts 四层知识面
- whole-book repair lanes 与 consistency diagnostics
- sample-based freeze gate 与 tracked evidence

## 5. 商业场景
- 网文工作室
- 编辑/审校团队
- 平台内容运营
- IP 策划与改编前置分析

## 6. 下一阶段能力建设
- retrieval 向 vector/entity-exact 升级
- risk semantic 向长窗口 adjudication 升级
- whole-book 增加更多真实 provider-backed evidence
- 文档/治理继续产品化
