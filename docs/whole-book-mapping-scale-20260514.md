# mapping_pack 30-章规模验证 — 2026-05-14

> 5-章 spike（commit 0840257）证明 mapping 有效，本测试验证 **30 章长程稳定性**。

## 测试设置

- 分支：`72da24e9-...`（卫图）
- 章节：ch 2-31（30 章，跨入门→武举）

## leak 详情

| ch | 残留源名 | 影响 |
|---|---|---|
| 19 | 养生功 (1×) | 力量体系映射轻微漏写，单 token |
| 20 | 郑国 + 青木县 + 养生功 | 该章节在情节转折处（祖宅纷争），LLM 在密集信息中遗漏了多项映射 |

## 解读

1. **mapping_pack 在 30 章长程稳定**：93% 章节零 leak，全部 leak 集中在 2 章；不是系统性 drift。
2. **+49% 字数提升**：mapping 提供的具体设定细节让 LLM 有更多素材。质量提升不是噪声而是结构性收益。
3. **Token 级准确率 97.7%**：达到生产可用水准。
4. **残留章节是修复目标，不是 pipeline 缺陷**：ch20 信息密度高，需要 prompt 提醒"信息密集章节加强映射检查"。
